# Code of conduct

Kubic adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its
code of conduct. Everyone who takes part in the project agrees to follow it.
It applies in this repository (issues, pull requests, discussions, reviews),
and wherever someone represents the project in public.

## Reporting

Report unacceptable behaviour to **team@konic.io**. Say what happened, where
and when, and include links or screenshots if you have them. A report that
concerns a maintainer is handled by the other maintainers, without the person
it concerns.

Every report is reviewed promptly and fairly, and the reporter's identity and
the details are kept confidential.

## Enforcement

The Konic maintainers enforce this code of conduct. They decide on each
report, following the Covenant's [enforcement
guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
a private correction, a warning, a temporary ban or a permanent ban, depending
on the impact of the behaviour.
