Notes — refer to these as 01-A, 01-B …

  • 01-AHeader: identity, project, branch (with a dirty-files dot), session name, approval state. The UUID moves to /session.
  • 01-BYour prompt is a raised surface with the red edge, so turns are easy to find when scrolling.
  • 01-CAssistant prose gets a quiet ◆ marker and full-contrast text. No colour on prose.
  • 01-DTool card: state dot, tool, target, then exit + duration on the right. Body is the useful slice only (no --- stdout ---, no temp-file paths). Footer says how much is hidden and how to expand or copy.
  • 01-ECheap, successful reads collapse to one line.
  • 01-FThinking collapses to one line with its first sentence; ^X expands it like any other output.
  • 01-GEdits show an inline diff with line numbers and a word-level highlight.
  • 01-IMarkdown: bold, file links (OSC 8, clickable), inline code on a raised cell background.
  • 01-JTurn receipt: time, tools, files, cost, and the two follow-up actions you are most likely to want.
  • 01-KEditor box with the red caret; hints on the right. Mid-turn it turns into a queue box.
  • 01-LOne status row: model + thinking, context gauge, cost, journal, state. Configurable segments later.
  • 01-MKey hints change with focus and state (idle vs working vs block mode). Esc never quits: it interrupts a running turn, or enters block mode from an idle, empty editor. ^C twice quits.
Open: full-screen (alt screen, as drawn) or inline in the normal terminal (native scrollback and selection, like Claude Code)? Header (A) and status (L) would stay; the transcript would scroll in your terminal instead.
