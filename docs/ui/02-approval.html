02 Approval cards

Approvals are inline, blocking cards that take over the editor slot — never a modal that hides the transcript. One key answers. Two variants: a risky shell command and a file edit.

Notes

  • 02-AThe card replaces the editor slot, so the transcript above stays readable (PgUp scrolls it).
  • 02-BAmber is the colour of "waiting for you" everywhere: header badge, tool dot, card frame, status text.
  • 02-CEach reason the policy flagged the call gets its own row (destructive, network, outside workspace…), in plain language.
  • 02-DSingle-key answers; the default for Esc/⏎ is the safe one (deny) and says so.
  • 02-EEdits preview the diff inside the card and show what comes next ("1 of 2").
  • 02-F"Deny + comment" sends the reason back to the model, so it can adjust instead of retrying blindly.
