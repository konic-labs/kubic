Notes

  • 03-AThe overlay floats over a dimmed screen; the background never moves.
  • 03-BResults are grouped (commands, models, sessions, files); fuzzy-matched letters are red.
  • 03-CThe selected row gets a raised surface and the red edge, the same focus language as your prompt.
  • 03-DModel picker groups by provider and says where each key comes from; providers without a key are shown greyed with the variable to set, instead of being hidden.
  • 03-EThinking level is chosen in the same picker (←→), so model + effort is one decision.
