Notes

  • 04-AHeader carries the mode badge (red = orchestrator) and live counts by state.
  • 04-BThe run timeline shows where the plan is: plan → implement → review → merge → verify.
  • 04-CWorkers are grouped by what they need from you: awaiting first (amber), then working, done, queued.
  • 04-DThe right pane is a live peek of the selected worker: its own tool cards, diff and budget.
  • 04-ERun-wide budgets as gauges; a gauge turns amber at 80% and red at 100%.
  • 04-FOne input: message the selected worker, or dispatch a new one.
