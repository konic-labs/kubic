Notes

  • 05-AWordmark: two rows of half-block glyphs in Konic red. Works in any terminal font; no large ASCII banner.
  • 05-BPreflight answers "can I start?" in five lines: provider, project, trust, journal, isolation.
  • 05-COnly when a project config exists. The question is asked just before the screen opens (the config must be decided before the agent boots), as a one-key prompt; this row then shows the decision.
  • 05-DThe honest isolation note stays, but as one calm line with a /safety link instead of a permanent two-line footer.
  • 05-EOnly five keys are shown up front; ? lists the rest.
  • 05-FA missing key is a red check with the exact fix, printed to the terminal so the export lines stay in your scrollback; then kubic exits with code 6. A running process never sees a key exported in another shell, so there is no "re-check" key.
