Notes

  • 06-AHelp is grouped by job, with examples. kubic alone opens the TUI on a terminal (first run: setup, 06-E).
  • 06-Brun streams one line per tool call on stderr while working; the answer and a receipt land on stdout. The three-line safety warning becomes one line.
  • 06-CDoctor prints a grouped summary with ✓ / ▲ / ✕; today's full text moves behind --verbose.
  • 06-DTables align, mark the default, and say which providers lack a key.
  • 06-FErrors: what failed, which input caused it, a suggestion, then the machine code in faint text.
