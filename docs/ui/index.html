■ Kubic — terminal design, v0.1

Draft for review. Every screen is drawn on a real character grid (one row = one terminal line, colours per cell), so what you approve here can be built 1:1 on pi-tui. Comment by note id, e.g. "01-D: …".

Principles

One hot colourKonic red means identity and focus only: the logo, the caret, the selected row, your prompt edge. Status uses its own colours.
Surfaces, not linesHierarchy comes from three background levels and three text levels. Rules are faint; boxes are rare.
Every block earns its rowNo permanent banners. Headers, status and key hints are one row each; tool output shows the useful slice.
Say the stateWaiting, working, failed, done each have one glyph and one colour, used the same way in the TUI and the CLI.
Keys follow focusThe hint row shows only what works right now. Esc backs out; it never quits.
Plain when pipedColour, spinners and boxes are a TTY layer. --json, pipes and NO_COLOR get the stable text the contract pins.
